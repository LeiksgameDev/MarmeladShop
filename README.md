## 📌 О проекте

<b>МармеладШоп43</b> — веб-приложение интернет-магазина сладостей.

Сайт позволяет пользователям просматривать каталог товаров, открывать подробные страницы продукции, регистрироваться, авторизовываться, добавлять товары в корзину и оформлять заказы.

Проект был разработан для автоматизации процесса продажи товаров через интернет и упрощения работы с ассортиментом и заказами.

## 🎯 Цель проекта

До создания сайта заказы могли приниматься через телефон или мессенджеры. Такой способ работы мог приводить к ошибкам при передаче информации о товарах, количестве и данных покупателя.

Основными целями проекта стали:

<ul>
  <li>создание удобного онлайн-каталога;</li>
  <li>автоматизация оформления заказов;</li>
  <li>хранение данных о товарах и пользователях;</li>
  <li>упрощение управления ассортиментом;</li>
  <li>сокращение количества ошибок при обработке заказов.</li>
</ul>

Для управления содержимым интернет-магазина была разработана отдельная административная панель.

Она защищена паролем и отделена от пользовательской части сайта.

## 🗄 Структура базы данных

В базе данных хранятся сведения о:

<ul>
  <li>зарегистрированных пользователях;</li>
  <li>товарах;</li>
  <li>категориях товаров;</li>
  <li>ценах и скидках;</li>
  <li>остатках продукции;</li>
  <li>заказах;</li>
  <li>товарах, входящих в каждый заказ.</li>
</ul>

Связи между таблицами позволяют сохранять информацию о покупателе, составе заказа и стоимости выбранных товаров.
